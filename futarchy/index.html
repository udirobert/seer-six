Futarchy

Futarchy is the proposal that a community should vote on what to do by asking what it is worth, not what people say. Seer builds the type: — markets on Gnosis chain, every one of them a single governance question priced in two numéraires at once — GNO and wxDAI — because the quantity a futarchy needs is not “will this pass” but “how much more valuable is the token if it does”. Not one of them has a price. So this surface draws the shape the price would occupy, empty, and names every field that is standing in for a number.

One question, four tokens

The Conditional Tokens Framework mints a complete set per outcome, so a futarchy row is a two-by-two: the same Yes/No asked twice, once collateralised in each numéraire. Splitting the question is the widest interval in the motion contract, because the relation genuinely is one-to-many — and with motion removed the same four cells are already on screen as a grid, which is the claim this whole entry is built on.
