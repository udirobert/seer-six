Document seven · not a surface — the rules the six obey

The motion contract

Six surfaces sharing a palette can still feel like six products. What makes them one product is that the same market survives being handed from one to the other, and that the time the hand-over takes is a fact about the data rather than a preference about the feel. So every interval on this site was fixed before any of it was built, from a relation in Seer’s API or an operation in the Conditional Tokens Framework, and lives in one stylesheet. This page reads that stylesheet back out of your browser and prints what it finds — including the exceptions I have admitted to rather than hidden. Press R at any moment: the argument only holds if the same information is still on screen when the motion is gone, and section 5 counts the frames that proves it.

1 · One scale, five steps

There are five durations in this system and no others. Each bar below is drawn at a width proportional to the value the browser actually resolved for the token, not to a number copied into prose — so if the stylesheet and this page ever disagree, the bar moves and the check under it fails.

    2 · Nine legs, and the relation each one stands for

    A leg is the relation between the document you left and the document you arrive at. Six are taken across a real page boundary, two inside a single page, and one is the deliberate absence of all of them. rehearse plays that leg on the stage to the right, against the same keyframes and the same two tokens — it is not a substitute for the cross-document case, which can only happen between two documents. take it performs the real navigation, which is why it leaves this page; it leaves from here, so the badge reads from: contract, and inside the product the same leg is taken from the surface named in the source line.

      3 · Enforcement: the stylesheet and the scripts, audited in your browser

So this section fetches every stylesheet and every script in the entry, parses them with the browser’s own CSSOM, walks every declaration whose property is a duration or a transition shorthand, and classifies the value. A number that is not a token reference appears here as a violation, on the page that is making the claim — it cannot rot quietly when someone edits a file at two in the morning.

        4 · What survives the removal of the motion

        This is the part of the argument the rest of the field has not made, and it is the part that decides whether any of the above was engineering or decoration. Under prefers-reduced-motion: reduce — or the hand switch, R, so you can test it without leaving your seat — nothing here eases. Every transition resolves to its end state at 0.01ms: a snap, never a pause halfway, because a paused element is information taken away and not given back.           And one property of the keyframes themselves is what makes the snap safe: every animation in motion.css ends at transform: none; opacity: 1 — the state its element was authored in. Nothing can be caught mid-flight by a system that only ever animates things back to where they already are.

          5 · The ledger, measured in your browser this session

          Every arrival at every one of the seven documents samples document.getAnimations() for seventy frames — roughly the first 1.2 seconds — and writes what it saw into this browser’s session storage. What matters is the longest unbroken run of frames in which something was running: with motion on, a leg’s run is the leg’s duration; with motion reduced it is at most one frame — a 0.01 ms snap can still be caught alive by a single sample, so the milliseconds rather than the frame count are what separate a snap from a pause. The table prints the declared interval beside the measured one, and where the measurement runs longer than the leg it is because an in-page arrival animation — the root settling, the price ticking to its new value — is inside the same window. That is the difference between snapping and pausing, in numbers, and it is the only way to observe a cross-document transition at all — it lives for a few frames and then is gone, so the instrument has to run inside the document being transitioned into. Click around the six surfaces, come back here, and the table fills. Press R, do the same, and compare the two runs.

          7 · What this does not claim

          Reach

          • Cross-document view transitions are Chromium 126+ and Safari 18.2+; Firefox does not ship them yet. There, every page still stands alone at its own URL and the navigation happens as a cut. The ledger records no animations — so the claim degrades to “it works where the platform allows”, which is stated rather than hidden.
          • A leg in a URL is a declaration, not a promise. A cold arrival — a typed address, a pasted link, a reload — has no previous document, so the browser cuts whatever the query string says. The row for the arrival that put this page here usually demonstrates exactly that.
          • Nothing here is a WCAG certification. It is a set of measurements, run by tools/a11y.mjs over six documents × three viewports with reduced motion forced on, with contrast computed from rendered getComputedStyle values. Measured, not certified.

          Data

          • All prices, liquidity, verification states and histories are a prebaked snapshot of markets-search and markets-charts at the timestamp in the footer, with a live fetch behind ?live=1 on the explorer and risk surfaces only.
          • Nothing synthetic is presented as real. The Futarchy surface shows the fields the protocol actually returns — four outcome tokens, two collaterals, odds: null on all 398 rows — and the composed conditional pair on that page is labelled as composed.
          • The typeface is a disclosed substitution. The Electric Foundation kit specifies PP Neue Montreal and Inter Tight, both commercially licensed and not web-fontable here, so this ships self-hosted IBM Plex under the SIL Open Font License with the licensed names still first in the stack. The departure is in the rationale, not buried in a stylesheet.

          Why motion is allowed to mean anything at all

          • Heer & Robertson, 2007 — Animated Transitions in Statistical Data Graphics, IEEE TVCG 13(6):1240–1247. The load-bearing citation: transitions between two views of changing data measurably improve a reader’s ability to track which object changed and by how much. A price is exactly such a change, and a market seen in a list and then on its own page is one object in two views.
          • Kim, Yoon, Whang, Tversky & Morrison, 2007 — The effect of animation on comprehension. Included deliberately, because it is the boundary condition: animation frequently fails to help and splits attention when it is decorative. The rule this page enforces exists to stay inside that finding rather than argue with it.
          • UX in Motion Manifesto — Issara Willenskomer. Continuity, relationship and expectation as named usability functions of interface motion — the industry vocabulary for the claim the ledger measures.
          • CSS View Transitions, Level 2 — W3C draft. The cross-document case, which is what lets a market object travel between two standalone URLs rather than two routes inside one application.
          • Seer documentation index and app.seer.pm. Every field name in the table above is quoted from the API these documents describe.
